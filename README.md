# Tic Tac Toe AI

A simple Tic Tac Toe game built using HTML, CSS, and JavaScript where the player (X) competes against an AI opponent (O).

## Features

* Human vs AI gameplay
* Win and draw detection
* Restart button
* Responsive UI

## How to Run

1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Play the game.

## Technologies Used

* HTML
* CSS
* JavaScript
